Современный минималистичный просмотрщик фотографий для Windows, созданный на WPF с использованием аппаратного ускорения.

## Поддерживаемые форматы

Snap поддерживает все популярные форматы изображений:
- **JPEG** (.jpg, .jpeg)
- **PNG** (.png)
- **GIF** (.gif — включая воспроизведение анимаций)
- **WEBP** (.webp — современный формат из интернета)
- **TIFF** (.tif, .tiff — профессиональные изображения в высоком качестве)
- **BMP** (.bmp)
- **SVG** (.svg — векторная графика)
- **ICO** (.ico — иконки Windows)
